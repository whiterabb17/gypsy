# 🎩 Gypsy (v0.3.0): The Hardened, Stateful TUI Agent

![Rust](https://img.shields.io/badge/language-Rust-orange.svg) ![Status: Production-Ready](https://img.shields.io/badge/Status-Production--Ready-brightgreen.svg) ![Mentalist](https://img.shields.io/badge/Runtime-Mentalist--v0.4.0-blue.svg) ![MindPalace](https://img.shields.io/badge/Memory-MindPalace--v0.4.0-magenta.svg)

**Gypsy** is the flagship Terminal User Interface (TUI) agent for the **MindPalace** ecosystem. Built on the **Mentalist** cognitive runtime, it provides a professional-grade, stateful workbench for high-agency automation, multi-agent coordination, and secure filesystem operations.

---

## 🏗️ The DeepAgent Architecture

Gypsy is built using the **DeepAgent** methodology, which treats the AI as a unified entity composed of three critical pillars:

1.  **Unified Model Engine**: Deduplicated, thread-safe access to local (Ollama) or cloud (Anthropic, OpenAI, Gemini) LLMs and embedding providers.
2.  **Mentalist Cognitive Harness**: A 5-phase execution loop (`PLAN -> EXECUTE -> CRITIQUE -> STORE -> ADAPT`) that ensures rigorous reasoning and goal alignment.
3.  **MindPalace Memory Core**: A hardened, 7-layer persistence stack that provides resilient long-term memory and proactive context optimization.

## 🕹️ Operational Workbench (Commands)

Gypsy treats the terminal as a mission-critical workspace. Use the command system (`/`) to control the agent and its environment:

-   **/consume**: **Study Mode**. Recursively walks and indexes the project directory into local knowledge for RAG.
-   **/summarize**: **Direct Optimization**. Manually triggers the 7-layer pipeline to compact context without losing intent.
-   **/review**: **Audit Mode**. Triggers an AI review of all files staged in the **Staging Vault**.
-   **/approve**: **Safety Gate**. Approves a pending multi-step execution plan generated by the cognitive runtime.
-   **/skills**: **Capability Discovery**. Lists all discovered agent skills from the local `skills/` directory.
-   **/mcp [list|enable|disable]**: **Infrastructure Management**. Hot-swap Model Context Protocol (MCP) servers at runtime.
-   **/session [list|switch]**: **Mission Lifecycle**. Manage and swap between persistent agent sessions.

## 🛡️ Security & Hardening

-   **Staging Vault Architecture**: All filesystem operations are performed in a secure `.agent/vault` directory. Changes only touch your project root after manual approval.
-   **Execution Isolation**: Gypsy supports Wasm-based sandboxing for untrusted tool kernels, enforcing strict memory and CPU fuel limits.
-   **SecurityEngine Policies**: Every tool call is validated against a capability-based security policy before execution.

# Build the release binary

# Initialize environment
cp .env.example .env

# Run Gypsy
./target/release/gypsy
